# Turtle Field Portfolio

An interactive portfolio built with Next.js 16, React 19, Tailwind CSS 4, and Base UI.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Quality checks

```bash
npm run lint
npm run typecheck
npm run format:check
npm run build
```

## Deploy to Vercel

Import this repository into Vercel and keep the detected Next.js defaults. No custom build command, output directory, or host configuration is required.

Vercel deployment URLs are detected automatically for social metadata. Set `NEXT_PUBLIC_SITE_URL` only when you want to use a custom production domain as the canonical social-image origin.
